# 操作指南：迁移后运行 Gold Evidence 逐跳 ReDeeP

## AutoDL SSH 连接

如果提供商域名在本机 DNS 不稳定，可在本机 `~/.ssh/config` 中配置别名（IP 和端口以 AutoDL 控制台当前值为准）：

```sshconfig
Host autodl-westc
  HostName 116.172.66.186
  Port 26078
  User root
  IdentityFile ~/.ssh/id_ed25519
  HostKeyAlias autodl-westc
  ServerAliveInterval 30
  ServerAliveCountMax 3
```

之后使用：

```bash
ssh autodl-westc
```

连接后进入项目：

```bash
cd /root/autodl-tmp/multihop-rag
source /root/miniconda3/etc/profile.d/conda.sh
conda activate multihop-rag
```

当前正式实验不使用 Wiki18、BM25 或检索器。三数据集已经提供支持证据；HotpotQA 使用补齐后的 `*_gold.jsonl`。

## 3. 逐跳生成 smoke test

不要一开始运行完整数据集。先运行 5 条：

```bash
PYTHONPATH=. python -m src.run_oracle \
  --input data/FlashRAG_Data/musique/dev.jsonl \
  --dataset musique --model model/Qwen3-4B-Instruct-2507 \
  --max-records 5 --output outputs/musique_dev_oracle.jsonl
```

HotpotQA：

```bash
PYTHONPATH=. python -m src.run_oracle \
  --input data/FlashRAG_Data/hotpotqa/dev_gold.jsonl \
  --dataset hotpotqa --model model/Qwen3-4B-Instruct-2507 \
  --max-records 5 --output outputs/hotpotqa_dev_oracle.jsonl
```

2WikiMultiHopQA：

```bash
PYTHONPATH=. python -m src.run_oracle \
  --input data/FlashRAG_Data/2wikimultihopqa/dev.jsonl \
  --dataset 2wikimultihopqa --model model/Qwen3-4B-Instruct-2507 \
  --max-records 5 --output outputs/2wiki_dev_oracle.jsonl
```

每一跳只输入该 hop 的 gold evidence；后一跳额外输入前一跳中间结果。GPU 利用率在分词或写盘时短暂为 0 属于正常现象。

程序会自动使用 Qwen 官方 chat template；不要在运行命令中手工添加聊天特殊 token。MuSiQue 的当前子问题会自动加入对应 hop，gold intermediate answer 仅用于检查，不会输入模型。

## 4. ReDeeP 校准和评估

先生成一个 train 子集和 dev 子集：

```bash
PYTHONPATH=. python -m src.run_oracle \
  --input data/FlashRAG_Data/musique/train.jsonl --dataset musique \
  --max-records 500 --sampling-strategy random --seed 42 \
  --output outputs/musique_train_oracle.jsonl
PYTHONPATH=. python -m src.run_oracle \
  --input data/FlashRAG_Data/musique/dev.jsonl --dataset musique \
  --max-records 100 --output outputs/musique_dev_oracle.jsonl
```

拟合并评估：

```bash
PYTHONPATH=. python -m src.run_redeep fit \
  --input outputs/musique_train_oracle.jsonl \
  --output outputs/redeep_musique_train.jsonl \
  --calibration outputs/redeep_musique.json --no-token-scores

PYTHONPATH=. python -m src.run_redeep evaluate \
  --input outputs/musique_dev_oracle.jsonl \
  --output outputs/redeep_musique_dev.jsonl \
  --calibration outputs/redeep_musique.json --no-token-scores
```

三个数据集分别校准，不要用数据集 dev 重新选择 heads/layers。`fit` 会从 train trace 内部分层留出 20% validation，在其中搜索 `K_head/K_layer=1..min(32, 实际候选数)` 和 `alpha=0.1..1.9`。正式实现只运行 token 模式，PKS 使用标准数学 JSD。最终标签统一为 `answer_f1 <= 0.30` 时幻觉。

## 5. HotpotQA Parquet 重新转换

如果 gold JSONL 损坏，可用已上传的 Parquet 重新生成：

```bash
PYTHONPATH=. python scripts/prepare_hotpot_from_parquet.py \
  --input data/FlashRAG_Data/hotpotqa/dev.jsonl \
  --output data/FlashRAG_Data/hotpotqa/dev_gold.jsonl \
  --parquet data/original_hotpotqa/hf_distractor/validation-00000-of-00001.parquet

PYTHONPATH=. python scripts/prepare_hotpot_from_parquet.py \
  --input data/FlashRAG_Data/hotpotqa/train.jsonl \
  --output data/FlashRAG_Data/hotpotqa/train_gold.jsonl \
  --parquet data/original_hotpotqa/hf_distractor/train-00000-of-00002.parquet \
           data/original_hotpotqa/hf_distractor/train-00001-of-00002.parquet
```
